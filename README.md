# teste-orce

## Task Management System

This project now includes a comprehensive Task Management System featuring:

- **Task Creation & Management**: Create, update, delete, and complete tasks.
- **Prioritization**: Support for Low, Medium, High, and Critical priority levels.
- **Tagging**: Add tags to organize tasks.
- **Filtering**: Advanced filtering by status, priority, assignee, and search query.
- **Utilities**: Date and String manipulation helpers.
- **Unit Tests**: Comprehensive test suite for the Task Manager.

### Structure

- `src/models`: Type definitions and interfaces.
- `src/services`: Core business logic (TaskManager).
- `src/utils`: Helper classes.
- `tests`: Unit tests.
